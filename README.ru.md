**Гелиоз** — конвейер непрерывной работы 24/7, составная часть **пантеона Olympuz** — родня Зевсу (фабрика систем), Мнемозине (память), Фемиде (юрпрактика) и самому Олимпузу (кокпит роя). Его удел — непрерывные прогоны: владелец спускает задачи, и работа не стоит никогда. Ночью владельца не будят — решает совет независимых советников (метод Карпаты), а в Telegram (бот «Зевс») летят тихие отбивки, чтобы утром любое решение можно было переиграть. Как Гелиос без единого выходного гонит колесницу по небу, так конвейер едет, пока все спят.

## Зачем

Автономный агент охотно рапортует «готово» без доказательств, подделывает собственные галочки, будит в три ночи из-за пустячной развилки или молча умирает вместе со всем, что знал. Гелиоз на каждое из этого отвечает прибором, а не обещанием:

- **Состояние живёт на диске, не в памяти агента.** Убей оркестратора в любой момент — следующий продолжит по прибору.
- **Маркер «сделано» пишет только код** — с коммитами до/после, хэшем изменённых файлов и кодом возврата проверки. Рукописный, обрезанный или скопированный маркер детектится как `tampered`.
- **Генератор не судит себя.** Исполнитель и проверяющий — разные CLI (claude / codex / kimi, живой зонд, ротация); проверяющий не видит отчёт исполнителя — только диск.
- **Три случая эскалации** доходят до владельца (прод, конфликт с чужой работой, дорогой откат). Остальное решается дефолтом, а ночью — советом линз, обязанным служить конечной цели владельца — или воздержаться.
- **Fail-closed везде.** Пустая очередь — красный. Нечитаемое состояние — красный. Совет без цели владельца отказывается решать.

## Поток

```text
владелец: цель → queue/GOAL.md · задачи → queue/tasks/*.task.md (без check_cmd не принимается)
   ↓
такт оркестратора:  beat → poll Зевса → бюджет → ready → зонд CLI → start (код блокирует пересечения путей)
   → исполнитель (headless CLI, фоном) → слепой проверяющий (другой CLI)
   → gate --task: check_cmd + враждебная проба → маркер целостности → finish → отбивка в Telegram
   ↓
развилка? → три случая владельца ждут в очереди (конвейер работает дальше) · ночные default — совету
   (линзы изолированно → слепой синтез → решение обязано служить цели → ledger) → утром можно переиграть
   ↓
контекст на исходе → хэндофф → сторож (launchd) поднимает свежего оркестратора с диска. Ничего не теряется.
```

## Раскладка

| Путь | Что |
|---|---|
| `ORCHESTRATOR.md` | замороженный промт оркестратора (такт выше) |
| `scripts/helioz-gate.mjs` | очередь, слоты, граф зависимостей, маркеры с tampered-детектом, STOP, бюджет, `--adopt` |
| `scripts/helioz-zeus.mjs` | канал Telegram: durable outbox → best-effort доставка, кнопки развилок, стоп/пуск/переиграть |
| `scripts/helioz-exec.mjs` | честный зонд CLI (настоящий прогон, не версия), ротация, запуск ролей |
| `scripts/helioz-council.mjs` | ночной совет: линзы изолированно → слепой синтез → ledger; запретные случаи — отказ |
| `scripts/helioz-watchdog.sh` | протухший heartbeat → новая сессия оркестратора с хэндоффом |
| `scripts/helioz-probes.mjs` | шесть сквозных враждебных проб; единственный писатель `READY.json` |
| `docs/CONTRACTS.md` | контракты состояния на диске (задачи, развилки, маркеры, ledger) |
| `docs/BRAND.md` | дизайн-описание: канон пиксельного пантеона |

## Запуск

```bash
bash scripts/helioz-start.sh
```

Владелец управляет из Telegram: кнопки под развилкой или «<id развилки> <номер>»; «стоп» замораживает всё без потерь, «пуск» продолжает.

Шесть враждебных проб обязаны быть зелёными (`node scripts/helioz-probes.mjs`): смерть оркестратора посреди задачи, поддельный маркер, суточное молчание владельца, недоступный Telegram, запретная развилка совету, два исполнителя на пересекающихся файлах.
