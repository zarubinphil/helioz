## Кто я

Привет. Я Гелиоз.

В старых историях я каждый день гнал солнечную колесницу по небу. Без выходных, без праздников, без «сегодня не хочется». Солнце вставало, потому что я работал.

Теперь то же самое я делаю с задачами.

Меня собрал Филипп Зарубин — юрист и отец двух дочек. Причина скучная: у него катастрофически мало времени. Ночь, суд, дети — а работа стоит, потому что некому её везти. Теперь везу я.

Я часть семьи: [Олимпуз](https://github.com/zarubinphil/olympuz) — кокпит роя, [Зевс](https://github.com/zarubinphil/zeuz) — фабрика, которая рождает такие системы, [Мнемозина](https://github.com/zarubinphil/mnemazine) — память, [Фемида](https://github.com/zarubinphil/themis) — юрпрактика, [Афина](https://github.com/zarubinphil/athena) — агентная ОС, на которой всё это живёт. Мой удел в этой семье один: непрерывность. Чтобы работа шла, пока ты спишь.

## Зачем я нужен (совсем просто)

Представь работника, который умеет всё, но у него три беды. Он говорит «сделал», когда не сделал. Он будит тебя в три ночи из-за ерунды. И он забывает всё, стоит его выключить.

Я на каждую беду отвечаю не обещанием, а прибором:

**«Сделал» проверяет не он, а программа.** Один агент работает, ДРУГОЙ проверяет — и проверяющий не читает отчёт первого, смотрит только на диск и гоняет команды. Никто не ставит оценку сам себе. Даже я.

**Отметку «готово» ставит код.** В отметке лежат отпечатки: какие коммиты были до и после, хэш изменённых файлов, код возврата проверки. Подделать её нельзя — рукописную, обрезанную или скопированную с чужой задачи я вижу и объявляю подделкой.

**Ночью тебя никто не будит.** Мелкие развилки решает совет из нескольких независимых советников: один смотрит на риск, другой на цену отката, третий на простоту. Каждый пишет позицию, не видя чужих. Потом решение сверяется с твоей целью. Утром читаешь, что решили, и можешь одним сообщением переиграть.

**Три вещи я не решаю никогда:** выход в прод, конфликт с чужой работой и развилку, где любой вариант дорого откатывать. Тут жду тебя. Но пока жду — работаю над остальным. Я не стою.

**Убей меня в любой момент — ничего не пропадёт.** Всё, что я знаю, лежит на диске, а не в моей голове. Следующий я продолжит с той же строчки.

**Пустое — красное.** Пустая очередь, нечитаемое состояние, совет без твоей цели — всё это отказ, а не «ну ладно, сойдёт». Ворота, которые зеленеют на пустоте, хуже отсутствующих.

## Как это выглядит на деле

Ты даёшь мне цель — одним файлом `queue/GOAL.md`. Это мой компас: каждое решение, принятое без тебя, я сверяю с ним.

Задачи кладёшь в `queue/tasks/`. У каждой обязана быть команда проверки. Нет команды — задачу не возьму: «готово» без доказательства это не готово.

Дальше я еду сам:

```text
цель → queue/GOAL.md · задачи → queue/tasks/*.task.md (без команды проверки не принимаю)
   ↓
такт: пульс → забрать твои ответы из Telegram → бюджет → выбрать задачу → зонд агентов
   → запуск (код не даст двоим тронуть один файл) → исполнитель → слепой проверяющий
   → команда проверки + враждебная проба → отметка целостности → отбивка тебе
   ↓
развилка? три твоих случая ждут в очереди, я работаю дальше · ночные мелкие — совету
   (линзы врозь → слепой синтез → сверка с целью → журнал) → утром переигрываешь
   ↓
контекст кончается → хэндофф → сторож поднимает свежую сессию с диска. Ничего не теряется.
```

Обо всём важном пишу в Telegram: этап, процент, что пошло не так и как выкрутился — простым языком, без кода. Скажешь «стоп» — замру, ничего не потеряв. Скажешь «пуск» — поеду дальше.

## Установка

```bash
git clone https://github.com/zarubinphil/helioz.git ~/Проекты/helioz
cd ~/Проекты/helioz
bash install.sh
```

`install.sh` сначала знакомится и объясняет, как я устроен, потом проверяет, что у тебя есть (Node, git, хотя бы один агент-CLI: claude, codex или kimi), гоняет мои приборы на селф-тестах и говорит, что осталось сделать руками. Нужен macOS или Linux и Node.js 20+.

Запуск после установки:

```bash
bash scripts/helioz-start.sh
```

## Что внутри

| Путь | Что делает |
|---|---|
| `ORCHESTRATOR.md` | замороженный промт оркестратора — тот самый такт выше |
| `scripts/helioz-gate.mjs` | очередь, слоты, зависимости, отметки с защитой от подделки, стоп, бюджет, приём чужой работы |
| `scripts/helioz-zeus.mjs` | Telegram: отбивки копятся на диске и доезжают, кнопки развилок, стоп/пуск/переиграть |
| `scripts/helioz-exec.mjs` | честный зонд агента (настоящий прогон, не проверка версии), ротация, запуск ролей |
| `scripts/helioz-council.mjs` | ночной совет: линзы врозь, слепой синтез, журнал; запретные случаи — отказ |
| `scripts/helioz-watchdog.sh` | пульс пропал → поднять новую сессию с хэндоффом |
| `scripts/helioz-probes.mjs` | шесть враждебных проб; только они дают проекту статус «готов» |
| `docs/CONTRACTS.md` | контракты состояния на диске: задачи, развилки, отметки, журнал |
| `docs/BRAND.md` | дизайн-описание, инстанс Pantheon Design System |

## Чем я доказываю, что не вру

Шесть проб гоняются одной командой и обязаны быть зелёными:

```bash
node scripts/helioz-probes.mjs
```

Убить оркестратора посреди задачи — следующий продолжает. Подделать отметку — ловится. Молчать сутки — работа идёт, развилки целы. Обрубить Telegram — отбивки копятся и доезжают. Дать совету запретную развилку — откажется решать. Пустить двоих на один файл — второй не стартует.

Пробы проверяют меня самого, а не мои слова о себе. Красная проба — статуса «готов» нет.
