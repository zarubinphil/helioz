## Промт исполнителя
Создай файл docs/LESSON-1.md в текущем рабочем каталоге (дом конвейера).

Содержимое (решение совета D001 — краткий состав, без лишних столбцов):
1. Заголовок `# CLI конвейера`.
2. Markdown-таблица ровно из двух столбцов: `CLI | Роли`.
3. По одной строке на каждый CLI из config/clis.json (ключи верхнего уровня, кроме начинающихся
   с подчёркивания). В столбце «Роли» — все значения поля roles этого CLI через запятую,
   дословно как в config/clis.json (например: execute, verify, advise, synthesize).
4. Одна строка после таблицы: «Источник: config/clis.json, состав по решению совета D001.»

Ничего не выдумывай — только данные из config/clis.json. Другие файлы не трогай.
После записи проверь себя командой: node scripts/lesson-check.mjs — добейся вывода «зелёный».

## Промт проверяющего
Ты проверяешь работу по ДИСКУ. Никаких отчётов исполнителя не существует.
Рабочий каталог — дом конвейера.

1. Прочитай config/clis.json и docs/LESSON-1.md.
2. Сверь: в таблице есть строка на каждый CLI верхнего уровня (кроме ключей с подчёркиванием),
   роли в строке дословно совпадают с полем roles, лишних CLI нет, состав краткий (CLI и роли,
   без столбцов веб-возможностей — решение совета D001).
3. Первая строка твоего ответа — строго «ВЕРДИКТ: зелёный» или «ВЕРДИКТ: красный».
   Дальше — причины по пунктам с точными расхождениями, если есть.
