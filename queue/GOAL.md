# Конечная цель владельца (миссия: вертикальный срез конвейера)

Конвейер непрерывной работы доказан живьём: одна учебная задача проходит весь путь
(очередь → исполнитель → проверяющий → маркер → отбивка → ночная развилка → совет → ledger →
утренняя сводка) без участия владельца, без потерь состояния и без нарушения запретов.
Решения обязаны служить надёжности и проверяемости конвейера, не красоте артефактов.
