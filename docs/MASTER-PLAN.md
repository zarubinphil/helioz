## Что уже стоит на диске и не переделывается

Завод `$BLOG_HOME` проходит приёмку `scripts/blog-factory-verify.mjs` на 121 проверке.
Работают: разведка добычи, сценарист через CLI, суфлёр, рендер терминала через vhs, рез пауз
на Silero VAD, транскрипт GigaAM со словарём терминов, субтитры группами по 1-3 слова,
сплит 46/54, кружок, голосовое, обложка, шесть текстов площадок, полуавтоматическая публикация,
прибор записи одного окна, чеклист заведения аккаунтов, прибор проверки ника.

Главный риск такта снят до планирования: запись одного окна через `screencapture -l<id> -v`
проверена, суфлёр и камера в кадр не попадают по построению.

## Волны

**Волна 1. Съёмка.** Владелец снимает первый живой атом прибором записи окна.
Задача T201. Всё остальное ждёт её, потому что без живого материала проверять нечего.

**Волна 2. Своё приложение, по нарастающей.** T202 экран в файл, T203 исключение своих окон,
T204 раздельные дорожки, T205 телефон как камера. Каждая задача даёт работающую вещь,
следующая её расширяет. Если владелец остановится после любой, у него останется рабочий инструмент.

**Волна 3. Свапы звеньев на готовое.** T206 и дальше по одному звену за раз, каждое через приёмку.

## Порядок и зависимости

```
T201 первый живой атом  (владелец снимает, завод собирает)
   |
   +-- T202 рекордер: экран в файл ---- T203 свои окна вне записи

   |                                              |
   |                                              +-- T205 телефон как камера

```
